# Marketplace Backend

Backend de un marketplace de productos, desarrollado con Spring Boot como proyecto de práctica.

## Stack
- Java 21
- Spring Boot 4
- Spring Data JPA / Hibernate
- PostgreSQL
- Spring Security + JWT (en progreso)

## Estado del proyecto
🚧 En desarrollo — modelo de datos completo (11 entidades JPA)

## Cómo correrlo localmente
1. Clona el repo
2. Crea una base de datos PostgreSQL llamada `marketplace_db`
3. Configura `src/main/resources/application.properties` con tus credenciales
4. Corre con `mvn spring-boot:run`
